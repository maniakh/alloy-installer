# alloy-installer

Installs Grafana Alloy (OpenTelemetry collector) from official Grafana repositories.

## Usage

```bash
git clone https://github.com/maniakh/alloy-installer.git
cd alloy-installer/ubuntu   # or debian / centos
sudo bash install.sh
```

## Supported OS
- Ubuntu
- Debian
- CentOS

## Uninstall

```bash
sudo bash uninstall.sh
```
